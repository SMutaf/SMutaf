## Areas of Focus

**Distributed Systems**
Designing services that communicate asynchronously, handle failures gracefully, and scale horizontally. I care about consistency, latency, and operational simplicity.

**Real-Time & Batch Data Processing**
Building pipelines that can switch gears — streaming live events or processing historical data in bulk. I've worked with backtesting workflows where the same logic needs to run across both.

**AI-Powered Microservices**
Embedding machine learning directly into service architectures. Not as a bolt-on, but as a first-class component — with proper separation of concerns and independent deployability.

**Clean Architecture & SOLID Principles**
I write code that future maintainers (including myself) can understand. Layered architecture, clear contracts between services, and deliberate design decisions over shortcuts.
